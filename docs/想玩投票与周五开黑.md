# 今天玩啥与周五开黑

首页两个插画入口：今天玩啥 → `pages/play/play`；周五一起开黑 → `pages/friday/friday`。保留大厅、发车、我的三个原生底栏。

## 今天玩啥

- 任何已填写昵称资料且未封禁的用户，都可以创建多个「游戏＋平台＋可玩起止时间」选项。支持自由输入游戏；开始时间属于北京时间今天，结束时间晚于开始时间和当前时间，最长24小时，可跨午夜。
- 创建选项默认自己想玩。每个用户可同时加入多个选项，同一选项一人一票，可在发车前取消。
- 至少两名有效用户想玩后，任何用户都可一键发车；点击者成为车头，之前投票的人自动上车，点击者未投票也会加入。封禁或资料失效者不自动上车，也不满足两人门槛。
- 发车直接创建真实队伍，在大厅、我的队伍和选项卡均可查看。多人同时发车、重复请求会返回同一队伍，不重复建车。
- 发车后，选项仍保留；其他人点「想玩并上车」同步记票并上车，已从大厅上车的人不会重复占位。已经上车的人从详情退出，投票意向保留，可以再次上车。已散或结束后不再加入。
- 默认每车最多20人（沿用现有上限），发车前每选项最多20名想玩者；每个北京时间日期最多50个选项。凌晨切换今天的清单，已经创建的车继续显示在大厅和我的队伍直到结束。
- 游戏、平台和时间代表已确认的共同意向，发车后保留；车头可以编辑房间/加入方式、人数、备注等其他信息。初始加入方式提示通过车头公开资料联系，车头可在详情补充实际房间。
- 投票和自动上车不会自行授予微信订阅提醒权限。

## 周五一起开黑

- 每周五21:00开场，默认21:00–23:00，北京时间；周五20:00从16款常见联机游戏中等概率随机抽一款，与票数无关、无人投票也能抽取。
- 候选包括 CS2、三角洲行动、英雄联盟、饥荒联机版、胡闹厨房2、求生之路2、深岩银河、致命公司、双人成行等。服务端目录为 `cloudfunctions/team/lib/play-games.json`。
- 截止后首次访问时事务生成并保存结果，不依赖定时触发器；所有人看到同一期同一结果。保留已有非空抽签结果；旧版本无票产生的空结果会补抽。
- 抽签后到本期结束前可发起游戏局，仍沿用现有发车表单、房间信息校验；用户自主加入具体队伍。
- 周六00:00切到下一期；修改周五队伍的游戏或开局时间后转为普通队伍。

## 接口与存储

- `getDailyPlay` 返回 `{ board: { dayId, serverNow, options } }`。选项返回游戏、时间、票数、本人是否想玩、队伍ID、人数、本人是否在车上和状态，不返回其他人的OpenID或投票名单。
- `createPlayOption({ gameName, platform, startAt, endAt, requestId })` 创建并默认自己想玩。同一用户同一天同一个requestId幂等，网络失败保留草稿和该key。
- `votePlayOption({ optionId, want })` 更新该选项意向；发车后want=true同时上车，want=false提示到详情下车。
- `launchPlayOption({ optionId })` 原子创建队伍、全部成员及选项关联，返回 `{ board, teamId }`。使用选项和队伍事务避免重复发车/重复占位，与普通上下车共用队伍人数锁。
- 写入成功后，若列表刷新失败，动作仍返回成功及teamId，board可为null；前端保留成功提示并提供列表重试，避免误报失败和重复发车。
- `daily_play` 按北京时间日期存选项ID；`play_options` 按稳定ID存游戏、时间、私有投票者快照及队伍关联。
- `weekly_play` 存每期抽签结果。`getWeeklyPlay` 获取周五活动；旧`votePlay`/`play_votes`兼容接口保留，但不影响随机结果。

## 部署与验收

1. 部署 `cloudfunctions/team`（包含lib目录），在云端安装依赖。确认 `daily_play`、`play_options`、`weekly_play`、`play_votes` 集合存在且只允许管理端访问，客户端仅经云函数访问。初始化会尝试创建集合。
2. 更新配套小程序前端。旧云函数不支持今天玩啥的新动作，单更新前端无法使用。
3. 账号A创建两个游戏/时间选项；B只对其中一个点想玩。刷新后，A有两个选项，选中的选项共2票。B取消后回到1票，发车按钮禁用。
4. B重新投票；A/B同时点击发车。应只有一趟车，首个成功点击者是车头，A/B自动上车，大厅和两人的我的队伍均可找到。
5. C从选项点想玩并上车，重复点击只占一席。D从大厅加入后再来选项投票，也不重复占席。C从详情下车再从选项上车，人数各减增一次。
6. 验证满员、散车、活动结束、跨日旧页面、资料缺失/封禁、网络错误和刷新恢复。车头补充房间信息成功；改游戏/时间提示另建选项。
7. 测试环境周五20:00前后验证：零投票也有随机游戏，所有账号结果一致，重读不重抽；21:00后仍可发车，23:00后不能发车；普通同名队伍不混入活动。
8. 验证群分享落地、房间密码不进入招募文案，以及 iOS/Android 的320/375px小屏布局。

本地浏览器仅验证界面，不代表真实云端持久化、微信登录或消息送达。QQ需其独立HTTPS后端实现相同接口；本次未部署服务或发布小程序。
