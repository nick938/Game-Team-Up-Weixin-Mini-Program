# 头像存储与权限兼容

2026-10-16

- 用户已在控制台将头像存储设为所有人可读。代码仍保存原始 `cloud://` fileID，读取时由 team 云函数换取 HTTPS 展示链接，兼容公开读和后续私有读规则，不把可读性绑定到固定日期。
- 环境套餐已有记录的到期时间为 2027-04-04 23:59:59；这是套餐期限，不是已核实的权限自动变更时间。到期前需在控制台核对续费、读写规则及服务可用性。代码不能在环境停服、文件删除或服务端无法签发链接时保证可读。
- 修改头像时先上传新选择的本地图片，已有 fileID 仅在未更换图片时复用。上传失败提示重试，不提示保存成功。
- 保存资料与读取资料都返回原始 avatarFileID 和展示 avatarUrl；数据库只保留 fileID。展示优先使用 avatarUrl，历史 base64 仅作无链接时的兼容。
- 发布需同时上传 team 云函数和微信前端。真机验收：两个账号互看新旧头像；已有头像再更换；只改昵称；模拟上传失败；在隔离测试资源上收紧读权限后重新进入详情与资料页。
- 目前未在真实云环境更改规则或验证套餐到期后的行为。链接只在接口读取时更新，页面长时间停留遇到链接到期需重新进入或下拉刷新。

参考：[CloudBase 云存储 SDK](https://docs.cloudbase.net/storage/sdk)。
