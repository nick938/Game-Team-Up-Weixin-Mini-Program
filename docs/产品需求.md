# 开一局 · 产品需求

> 版本：v0.2  
> 日期：2026-09-03  
> 范围：微信小程序 + 微信云开发  
> 状态：第一期开发中  
> 产品名：**开一局**

---

## 1. 产品是什么

给微信里想一起玩游戏的人用的组队工具。

发起人发一条组队信息（玩什么、什么时候、几缺几、房间号），把卡片分享到微信群或私聊。别人点开就能看详情、一键加入。人齐了开打，到点自动结束。

不做游戏本身，不做语音房，不做公会。只做「发车 → 分享 → 上车 → 开打」。

一句话：**微信里的开黑发车板。**

对外名称用 **开一局**：短、好叫、分享卡片上自然（「开一局｜王者荣耀 还差 2 人」）。不像游戏发行方，也不像工具后台。

---

## 2. 要解决的问题

现在大家组队靠群里喊、朋友圈、截图房间号。问题是：

- 信息散，过几分钟就被刷掉
- 房间号、人数、时间写在不同消息里，对不上
- 新人进群不知道还有没有位置
- 分享出去的人看不到「现在几缺几」

这个小程序把一条车的信息、人数、状态钉在一个可分享的页面上。

---

## 3. 目标用户

| 角色 | 是谁 | 典型场景 |
| --- | --- | --- |
| 车头（发起人） | 想凑一局的人 | 差 2 个打王者，发到群里等人 |
| 乘客（加入者） | 看到分享或在广场闲逛的人 | 点链接上车，或按游戏名找车 |
| 路人 | 第一次打开小程序 | 浏览正在招募的车，决定加不加 |

首期不做陌生人社交匹配算法，**分享进群是主路径，广场是辅路径。**

---

## 4. 核心场景

### 4.1 发车并拉人（主路径）

1. 车头填写：游戏、开始时间、人数、房间号/密码、备注
2. 发布成功，进入队伍详情
3. 点「分享给好友」，发到微信群或私聊
4. 群友点卡片进入详情，点「加入」（无需车头同意）
5. 人数满了，状态变为「已满员」，不能再加
6. 到开始时间自动变为「已过期」，不能再加入

### 4.2 接受邀请

1. 用户从分享卡片进入，落到**这一条队伍**的详情，而不是首页
2. 未填头像昵称时，先填写再加入
3. 已满、已取消、已过期时，说明原因，并给「看看别的车」入口

### 4.3 自己找车

1. 打开首页，看到正在招募的队伍列表
2. 可按游戏名筛选
3. 点进详情，加入或分享给别人

---

## 5. 组队信息（一条车里有什么）

### 5.1 必填

| 字段 | 说明 |
| --- | --- |
| 游戏名 | 选常用游戏，或自己填 |
| 开始时间 | 日期 + 时间。不能早于当前时间。到点即过期 |
| 需要人数 | 含车头。例如 5 人局 |
| 房间号 | 游戏内房间 / 房间码 / 邀请码。**未加入也直接显示** |

### 5.2 选填

| 字段 | 说明 |
| --- | --- |
| 房间密码 | 仅**已加入成员**可见 |
| 平台 | 手机 / PC / 主机 / 不限 |
| 区服 | 例如 微信区、QQ 区、亚服。自由文本 |
| 语音 | 开麦 / 听麦 / 不限 |
| 段位要求 | 自由文本，如「钻石以上」 |
| 备注 | 玩法、心态、麦序。≤ 80 字 |

### 5.3 系统生成

| 字段 | 含义 |
| --- | --- |
| 队伍 ID | 用于分享路径 |
| 车头 | 发布者 OpenID、昵称、头像 |
| 当前人数 / 缺几人 | 实时 |
| 状态 | 见第 7 节 |
| 创建时间、过期时间 | **过期时间 = 开始时间**（到点过期） |

### 5.4 首期游戏列表

内置常见项，可选手填：

王者荣耀、和平精英、原神、三角洲行动、无畏契约、CS2、Dota2、永劫无间、LOL、APEX、我的世界、其他（手填）

## 6. 功能范围

### 6.1 第一期（P0）— 本次做

- 微信身份：OpenID；发车/加入前填写头像、昵称
- 发布组队；未过期前车头可编辑
- 关闭组局（车头）；队员可退出组局
- 队伍详情：成员、缺几人、房间号（公开）
- 直接加入 / 退出，无需审批
- 车头踢人
- 分享到微信聊天（卡片带队伍 ID，落地详情页）
- 广场列表 + 游戏筛选
- 「我的」：我发起的、我加入的
- 状态：招募中 / 已满员 / 已取消 / 已过期
- 房间号公开；房间密码仅队员可见
- 同时段限制：进行中的队伍最多开 1 趟；加入不限制趟数。同一趟局里不能重复占两个位置。

### 6.2 第一期明确不做

- 车头审批加入
- 即时聊天、语音、视频
- 好友、关注、私信
- 游戏账号 / 战绩校验
- 付费
- 匹配推荐
- 朋友圈分享
- 「发车中」手动按钮（到点自动过期）

### 6.3 第二期（P1）

- 加入审批
- 订阅消息
- 小程序码
- 队伍留言板
- 再发一趟模板
- 复制房间号 / 密码（第一期详情里先做复制）

## 7. 队伍状态

```
招募中 ──人满──► 已满员
   │               │
   │               │有人退出且未到点
   │               ▼
   │            招募中
   │
   ├──车头取消──► 已取消
   └──到开始时间──► 已过期
```

第一期没有「进行中 / 已结束」。到点即过期。

| 状态 | 能否加入 | 分享卡片 |
| --- | --- | --- |
| 招募中 | 能 | 「开一局｜游戏名 还差 N 人 · HH:mm」 |
| 已满员 | 不能 | 「开一局｜游戏名 已满员」 |
| 已取消 | 不能 | 「开一局｜已取消」 |
| 已过期 | 不能 | 「开一局｜已结束」 |

车头占 1 个位置。满员与招募中随人数自动切换。

---

## 8. 权限

| 动作 | 车头 | 已加入成员 | 未加入访客 |
| --- | --- | --- | --- |
| 看游戏、时间、缺几人、备注 | ✓ | ✓ | ✓ |
| 看完整房间号 | ✓ | ✓ | ✓（直接显示） |
| 看房间密码 | ✓ | ✓ | 不可见 |
| 加入 | — | — | 招募中且未满 |
| 退出组局 | 不可退出，只能关闭整局 | ✓ | — |
| 踢人 | ✓ | — | — |
| 编辑信息 | 招募中 / 已满员（未过期） | — | — |
| 关闭组局 | ✓ | — | — |
| 分享 | ✓ | ✓ | ✓ |

约束：

- 同一用户同一条队伍只能加入一次
- 进行中（未过期、未取消）最多作为车头开 1 趟
- 进行中最多作为队员加入不限趟数；同一趟局不能重复加入
- 被踢后可以再加入（不拉黑）

「进行中」= 状态为招募中或已满员，且当前时间未到开始时间。

---

## 9. 分享与邀请

1. 分享标题：`开一局｜游戏名 还差 N 人 · HH:mm`
2. 分享内容：备注前 20 字，或「点开就能加入」
3. 落地页：`pages/team/detail?id=队伍ID`（不要先跳首页）
4. 房间号公开；密码加入后可见，可复制

---

## 10. 页面结构

```
广场（tab）
  ├─ 正在招募列表
  ├─ 游戏筛选
  └─ 发车入口

发车（tab，发布表单）
  └─ 成功后进详情；已有进行中的车则提示去详情

队伍详情（分享落地页，非 tab）
  ├─ 状态、缺几人、房间号
  ├─ 成员
  └─ 加入 / 退出 / 分享 / 车头操作

我的（tab）
  ├─ 头像昵称
  ├─ 我发起的
  └─ 我加入的
```

## 11. 数据（云开发）

### users

| 字段 | 含义 |
| --- | --- |
| `_openid` | 微信 OpenID |
| `nickName` | 昵称 |
| `avatarUrl` | 头像 fileID |
| `updatedAt` | 更新时间 |

### teams

| 字段 | 含义 |
| --- | --- |
| `_openid` | 车头 |
| `gameName` | 游戏名 |
| `startAt` | 开始时间（毫秒）。到点过期 |
| `expireAt` | 与 startAt 相同 |
| `capacity` | 总人数 |
| `memberCount` | 当前人数 |
| `roomNo` | 房间号（公开） |
| `roomPwd` | 房间密码（仅云函数按身份返回） |
| `platform` / `server` / `voice` / `rankReq` / `note` | 选填 |
| `hostNickName` / `hostAvatarUrl` | 列表展示用 |
| `status` | recruiting / full / cancelled |
| `createdAt` | 创建时间 |

过期不单独落库，读取时若 `now >= startAt` 且未取消，视为 expired。

### members

| 字段 | 含义 |
| --- | --- |
| `teamId` | 队伍 |
| `_openid` | 成员 |
| `role` | host / member |
| `nickName` / `avatarUrl` | 加入时快照 |
| `joinedAt` | 加入时间 |

写操作全部走云函数 `team`。加入用事务，防止超员。

## 12. 关键流程

### 发布

校验必填且开始时间在未来 → 检查没有进行中的「我开的车」→ 写 teams + 车头 member → 跳转详情。

### 加入

校验招募中、未满、未过期、未重复 → 检查没有进行中的「我加入的车」→ 事务写入 → 满员则 status=full。

### 退出 / 被踢

删 member → memberCount-1 → 未过期则满员改回招募中。

### 取消

仅车头；status=cancelled。

### 过期

懒过期：`now >= startAt` 视为已过期。列表查询 `startAt > now` 且未取消。

---

## 13. 体验细节

- 卡片一眼能看到：游戏名、时间、`3/5`、还差几人、房间号
- 1 小时内开打标「即将开始」
- 自己的车、已加入的车，列表打标记
- 房间号、密码可复制
- 空状态引导发车
- 分享进来已满：说明原因 + 「看看别的车」
- 时间展示为「今天 21:00 / 明天 14:00」
- 人数步进器，默认 5，范围 2–20

---

## 14. 内容与合规

- 备注 ≤ 80 字，房间号 ≤ 32 字，自定义游戏名 ≤ 20 字
- 云函数简单违禁词
- 「我的」预留下一期限：用户协议 / 隐私政策
- 类目走社交或工具，不挂游戏
- 头像昵称用官方 `chooseAvatar` + `type=nickname`，不用 `getUserInfo`
- 房间密码未加入不下发

## 16. 第一期验收

1. A 发一趟王者、今晚 9 点、5 人、房间号 123；未加入的人也能看到房间号
2. A 把卡片发到聊天，B 点开落在这条详情
3. B 填头像昵称后加入，看到密码（若有），人数 2/5
4. 满员后其他人加入失败
5. 有人退出后恢复招募中
6. A 能踢人、改信息、取消
7. 广场能按游戏名筛选
8. 「我的」里发起/加入分开
9. 到开始时间后不能再加入
10. A 进行中不能再开第二趟；B 进行中不能再加入第二趟

## 17. 已拍板（第一期）

| 项 | 结论 |
| --- | --- |
| 加入是否审批 | 否，直接加入 |
| 未加入是否显示房间号 | 直接显示 |
| 过期 | 到开始时间自动过期 |
| 同时段配额 | 开 1 趟；加入不限制 |
| 游戏名 | 列表 + 手填 |
| 名称 | **开一局** |

## 18. 开发顺序

1. 云函数 `team` + 资料
2. 发车 + 详情
3. 加入 / 退出 / 满员 / 踢人
4. 分享落地
5. 广场 + 筛选
6. 我的
7. 编辑 / 取消 / 到点过期 / 配额
