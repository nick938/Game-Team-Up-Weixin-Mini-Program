# 前端设计改版验证记录

日期：2026-10-19。设计基线：根目录 `design.md` v1.1。

## 实现范围

- 新增三层 Design Token、UnoCSS 与 Wot UI 2.3.2 适配和页面主题 hook；页面、导航、TabBar、组件与分享画布共用语义色。
- 统一最大内容宽度 560px，窄屏留白 12px，其余 16px；字体、间距、按钮和头像使用稳定的 px 尺寸。
- 重做队伍卡片、详情与发车表单，调整大厅、游戏页、个人中心；协议、反馈、报错、举报、管理和诊断页接入共享主题。
- 新增生命周期、招募状态和角色视图模型。开始和结束边界触发视图更新，详情重新读取状态；加入冲突后刷新，不重放写请求。
- 发车表单按四组展示，沿用原有字段校验，错误定位到字段，修正该字段时清除对应提示。
- 统一底部弹层主题，通过 RootPortal 传递 Wot 主题，自有内容显式绑定应用变量；沿用共享计数协调原生 TabBar。Wot 2.3.2 的选择器圆角依赖原组件祖先，Portal 模式在统一适配层中补齐同源圆角与裁切规则。
- 详情密码按服务端授权字段展示，已散普通成员显示不可见；共享卡片和画布只读取公开摘要字段。

本次未修改服务端业务规则、依赖版本和发布配置，未上传小程序。提交与推送状态以 Git 记录为准。
