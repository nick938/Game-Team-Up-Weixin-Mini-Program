## 视觉规范

沿用小程序本身的「清爽开黑风」：

- 主色：紫蓝 `#6255E7`，深色 `#4E42C4` / `#5549C7`
- 背景：浅灰 `#F5F6FA` 到浅紫的渐变
- 强调色：薄荷绿 `#7BE0C0`
- 素材：直接复用 `miniprogram/images/brand/avatar-v1.jpg`（头像）和 `lobby-v1.jpg`（大厅插画），保证配图和小程序长得像一家人
- 字体：Microsoft YaHei / PingFang SC

## 重新生成

图片是用 HTML + 无头 Edge 渲染的，不是位图手绘，改文案后可以整批重出：

```bash
cd docs/promo/_build
node gen.js          # 生成各渠道的 HTML
# 再用无头 Edge 把每个 HTML 截图成 PNG（尺寸见上表）
```

`_build/gen.js` 里集中放着所有文案和配色，改完重跑即可。

### 小程序分享卡片封面

群里转发的卡片封面单独一张，不属于上面这套推广图：

```bash
cd docs/promo/_build
node share-cover.js  # 输出 miniprogram/images/share/cover-v1.jpg
```

750 × 600（微信推荐的 5:4），走无头 Chrome 渲染。改标题或配色改 `share-cover.js` 里那段 HTML。
所有分享入口都通过 `miniprogram/utils/share.js` 引用它，所以换图不用动页面代码。

注意这张图现在是**兜底**：队伍详情页会实时用 canvas 画一张带「这趟车」信息的封面
（`miniprogram/utils/team-cover.js`，配色和排版照抄详情页首屏 hero 卡片）。只有在
封面还没画好或画失败时，才会落到这张静态品牌图。所以改品牌视觉时，这张图和
`team-cover.js` 里的 `COLORS` 要一起改，别让两种封面看起来不像一套。

## 注意

- 图片里的产品名统一是「开黑星球｜游戏搭子」。小程序代码里的品牌名已一并统一，重新编译后分享卡片会显示「开黑星球｜游戏名 …」，和这些配图一致。
- 抖音封面底部约 1/4 会被平台 UI（文案、音乐条）盖住，所以标题都放在上半部分。图文模式同样按此处理。
- 这些图是「品牌视觉图」，用于没有真实内容可展示时。等小程序里有真实的车，**优先用真机截图**（见推广文案第 8 节），真实截图比插画更能打动人。
