# 图一乐游戏组局助手 · 推广文案

> 品牌全称：**图一乐游戏组局助手**，简称 **图一乐**
> 覆盖渠道：朋友圈 / 微信群 · 小红书 · 小黑盒 · 抖音
> 用法：按渠道直接复制。发之前先看第 0 节，两类渠道口径不同。

---

## 0. 先看这里：两类渠道，两种口径

**微信生态内**（朋友圈、微信群、公众号、视频号）：可以直白引导，说「微信搜索『图一乐游戏组局助手』」「点开卡片上车」都没问题。

**站外平台**（小红书、抖音、B站、小黑盒）：**不要出现任何站外导流词**——「微信搜索」「加微信」「公众号」「私信我发你」都要避开，正文里连小程序名 + 「搜索」也建议少用。小红书和抖音都限制站外导流，轻则限流、重则删帖。站外只做一件事：**让人对「组队难」有共鸣、对产品好奇**；引导放到**评论区置顶**或**主页简介**，且要含蓄。

**名称写法**：第一次出现用全称「图一乐游戏组局助手」，之后可简称「图一乐」。对外的痛点表达可以用「开黑」「组局」「找队友」这类通用词，但产品名统一用「图一乐」，不要再用旧名。「图一乐」这个名字本身也自带「图一乐而已」的轻松感，很适合这个场景。

**别写错的功能边界**（以下都已和代码核对）：

- 开打提醒是**开打前 10 分钟**推一条，且只推给**授权了订阅**的队友，不是「车上每个人」。
- 每局最多只会收到**一条**通知。
- 一局最长 **24 小时**。
- **房间号公开**，**密码仅队员可见**。
- 大厅可以**按游戏名筛选**，缺人的车排在前面。

## 3. 小红书

> 小红书的逻辑是**搜索**：用户在搜「游戏搭子」「开黑」「找队友」。所以标题要带这些词，正文要像真实分享，不要像广告。**正文不出现「微信搜索」。**

**标题备选（≤20 字，挑一个）**

- 一个人打游戏真的会谢，我做了个组队工具
- 游戏搭子怎么找？开黑再也不用群里喊了
- 受够了群里刷屏喊人，我搞了个发车板
- 开黑凑不齐人？这样发一趟就有人上车

**正文**

```
作为一个天天想开黑、却永远凑不齐人的玩家，我真的受够了。

以前找一个队友的流程是这样的：
在群里喊 → 被表情包刷走 → 重新喊 → 有人问「还缺吗」→ 已经满了
或者房间号、人数、时间写在三条消息里，谁也看不明白。

后来我干脆自己做了个小工具（本人是开发者，不是恰饭🙏）

它的逻辑特别简单：
你发一条「车」，写清楚玩什么、几点开、几缺几、怎么进房，
它会生成一张卡片。把卡片丢进群或发给朋友，
对方点开就能看到还差几个人、几点开打、怎么进房，想玩点一下就上车，不用等谁同意。

我最喜欢的两点：
① 不用再一条条问「还有位置吗」，缺几人卡片上实时写着
② 人齐了自动变「满员」，到点自动结束，不用谁去群里喊「别加了」

平时在游戏群、游戏搭子群里用，比刷屏舒服太多。
而且它不用下载、不用注册，点开卡片就能用。
```


## 4. 小黑盒

> 盒友以 Steam 玩家为主，反感硬广，吃「开发者自己做了个东西」的真诚叙事。发在「盒友杂谈 / 综合讨论」一类板块，**别放外链**，名字用文字提。

**标题**：`差 2 个队友，我在群里喊了三遍——于是自己写了个组局小程序`

**正文**

```
先说背景：我是一个 CS2 玩家，也是做开发的。

每次想打游戏，最崩溃的不是枪法变菜，是凑人。
「还缺两个」发到群里，两分钟后被段子和表情包冲走。
有人看到想上车，还要私聊问「还缺吗」「几点」「房间号多少」。
等我一个个回完，人早散了。

后来我把这件事做成了个小程序，叫「图一乐游戏组局助手」。

核心就一个动作：发车。
选游戏、平台、开始结束时间、几缺几、进房方式，生成一张卡片。
把卡片发到群里，谁想玩点开看一眼就知道还差几人、几点开、怎么进房，点一下上车，不需要我挨个确认。

几个我比较满意的细节：
- 缺人数是实时的，不用一遍遍回「还缺 X 个」
- 人齐自动满员，到点自动结束，不用谁去喊「满了别加了」
- 开打前 10 分钟会推一条提醒（授权了订阅的队友才收到），不怕鸽
- 房间号公开，密码只给上车的队友看，陌生人拿不到
- 大厅能按游戏名找车，Steam / 手游 / 端游 / 主机都能发

不用下载不用注册，微信里就能用。

说实话做它的原因很朴素：就想安安稳稳找几个人打一局。
有同样痛点的盒友可以看看，也欢迎给我提意见，功能我还在改。
```

**标签**：`#CS2 #Steam #开黑 #组队 #独立开发`

## 9. 投放小提示

- **主战场是微信群**：分享卡片是主路径，大厅是辅路径。先在自己的游戏群跑起来，再去公开渠道。
- **卡片标题自带信息**：分享出去显示「图一乐游戏组局助手｜CS2 还差 2 人 · 21:00」，一句话就够勾人。
- **落地页是详情**：群友点开直接落到这趟车，不用先过首页，转化更顺。
- **提醒是召回点**：开打前 10 分钟的订阅消息，是让用户第二次打开小程序的好机会。
- **别在大厅空的时候大规模拉陌生人**：新用户进来看到没车会立刻走，且不会再来。先用微信群把大厅跑热。
- **合规**：不承诺游戏战绩、账号交易、代练；不引导站外（小红书/抖音）；不用「稳赢」「带飞」这类绝对化用词；不涉及未成年人不当消费。
