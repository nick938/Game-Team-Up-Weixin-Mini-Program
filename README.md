# 来开黑

微信小程序：给游戏好友发车组队（Steam / 手游 / 端游 / 主机），把卡片丢进群就能上车。

## 本地开发

1. 用微信开发者工具打开本目录，环境选 `cloud1`（`cloud1-d9gniyjzh4e2ffb1c`）
2. 右键 `cloudfunctions/team` → 上传并部署：云端安装依赖
3. 编译后从「发车」发一条，再从「大厅」或分享卡片上车

云函数第一次成功调用后，会自动创建 `users`、`teams`、`members` 三个集合。

## 订阅消息

已接入模板「游戏组局即将发车」（`6CGZ2ttjMY5Dl_PC2TrrXmrF-KT8awGU7SLPHif2EJ4`）：

| 字段 | 填什么 |
| --- | --- |
| 日程标题 `thing5` | 游戏名 |
| 开始时间 `time6` | 开打时间 |
| 备注 `thing11` | 即将开打，请准时上线 / 有人上车了 / 人已经齐了 / 你被请下车了 / 这趟已经散了 |

开打前 15 分钟，定时器会给车上所有人推「即将开打」。发车、车头点自己的车、点「开打前微信提醒我」时会请求授权。「有人上车 / 人齐了」只发给车头。

改模板后同步改 `constants.js` 和云函数 `sendSubscribe`，并重新上传 `team`（须带触发器）。
